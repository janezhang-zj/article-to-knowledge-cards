# make-knowledge-cards

把长文章提炼成 5~8 张结构化知识卡片，读完就能复习。

## 解决什么问题

读一篇长文（文章、课程笔记、TED 讲稿、播客文案）时，看完觉得懂了，过两天全忘。这个 Skill 帮你把文章里真正值得记住的东西，拆成一张张独立卡片——每张卡片只讲一个点，带例子和自测题，方便你反复回忆。

## 主要功能

- 接收粘贴的文本或本地 `.md` / `.txt` 文件，输出 5~8 张知识卡片
- 每张卡片固定四块：标题、核心知识（一句话）、解释（2~4 句）、例子或自测题
- 自动去重：同一观点在不同位置出现，合并成一张
- 信息不足时宁少勿滥，不硬凑数量，不编造原文没有的内容
- 一张卡片只讲一个知识点，标题具体不空泛

不支持：网页 URL 抓取、PDF、Anki 导入、图形界面。

## 安装方法

这是一个纯文本 Skill，不需要安装依赖。把整个 `skills/make-knowledge-cards/` 文件夹复制到你的 AI 助手的 skills 目录即可：

```
你的项目/
└── skills/
    └── make-knowledge-cards/
        ├── SKILL.md
        └── agents/
            └── openai.yaml
```

如果使用 OpenAI Agents SDK 或兼容框架，加载 `agents/openai.yaml` 作为 agent 配置即可。

## 使用方法

在加载了本 Skill 的助手中，任选一种方式：

1. **粘贴文本**：把文章直接贴进对话框，说"帮我做成知识卡片"
2. **指定文件**：给出 `.md` 或 `.txt` 文件路径，说"把这个文件做成知识卡片"

## 输入输出示例

**输入**（一段关于睡眠的文字）：

> 人的睡眠由多个 90 分钟周期组成。每个周期分为浅睡、深睡和 REM。如果你在深睡阶段被闹钟叫醒，就会出现睡眠惯性，醒来后昏沉 1~2 小时。咖啡因的半衰期是 6 小时，下午 3 点喝的咖啡到晚上 9 点体内还有一半，会显著减少深睡时间。

**输出**：

```
### 卡片 1：90 分钟睡眠周期

**核心知识：** 睡眠由多个 90 分钟周期组成，每个周期含浅睡、深睡和 REM。

**解释：** 深睡阶段身体修复，REM 阶段处理情绪记忆。

**例子：** 睡 7.5 小时（5 个完整周期）往往比睡 9 小时（在深睡中被打断）更精神。

---

### 卡片 2：咖啡因半衰期 6 小时

**核心知识：** 下午 3 点喝的咖啡，到晚上 9 点体内还有一半。

**解释：** 这会显著减少深睡时间，即使你觉得"喝了也能睡着"。

**自测：** 如果你晚上 11 点睡觉，最晚几点之前要喝完最后一杯咖啡？（答案：上午 11 点前）
```
