# Make Knowledge Cards

## Overview

把一篇文章提炼成 5~8 张可独立阅读的知识卡片，帮助快速复习和记忆。每张卡片只讲一个知识点。

## Input Sources

接受两种输入：

1. **用户直接粘贴的文本**：在对话中给出的文章内容。
2. **本地 Markdown / TXT 文件**：用户给出文件路径时，用 Read 工具读取全文。

不支持：网页 URL、PDF 扫描件、需要登录的页面。遇到这些情况直接说明不支持。

## Workflow

1. **通读全文**，标出所有核心概念、论点、方法、结论。
2. **去重合并**：同一观点在不同位置重复出现的，合并为一张卡片。
3. **筛选**：只保留真正重要的知识——去掉铺垫、过渡句、重复举例、常识性内容。
4. **拆成卡片**：每张卡片一个独立知识点。
   - 信息量充足 → 5~8 张。
   - 原文内容单薄、不足 5 张有价值卡片 → 按实际数量输出（可以少于 5 张），不要硬凑。
5. **写卡片**，按下面的格式输出。

## Card Format

每张卡片用统一结构：

```
### 卡片 N：[标题]

**核心知识：** 一句话说清这个知识点是什么。

**解释：** 2~4 句话讲明白原理、背景或为什么重要。

**例子 / 自测：** 给一个原文中的例子，或者提一个自测问题让读者回忆。
```

示例：

```
### 卡片 1：帕累托法则

**核心知识：** 80% 的结果来自 20% 的原因。

**解释：** 在大多数系统中，少数关键因素贡献了大部分产出。这意味着找到那 20% 的高杠杆点，比均匀用力更有效。

**例子：** 原文提到一家公司 80% 的收入来自 20% 的客户——资源应优先服务这部分客户。
```

## Rules

- **一张卡片只讲一个知识点**，不要把两个概念塞进同一张。
- **不能编造原文没有的信息**。例子优先用原文里的；原文没有合适例子时，可以出一道自测问题。
- **标题要具体**，不要用"引言""总结"这种空泛标题。
- **卡片数量 5~8 张为目标**，但信息不足时宁少勿滥。如果原文只有 3 个真正有价值的点，就出 3 张，并在开头说明"本文核心知识点较少，仅提炼出 N 张卡片"。
- 输出时每张卡片之间空一行，方便阅读。
